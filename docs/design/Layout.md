# Layout da Ficha

Ordem de exibição proposta:

1. Cabeçalho — Nome, Raça, Classe, Nível, Faixa Etária, Associação
2. Atributos — FOR, VIG, AGI, INT com indicador visual do pool de dados
3. Derivados — HP, Defesa, Iniciativa, Carga
4. Vontade — Barra de recursos (atual/máximo)
5. Roleplay — Motivação, Ponto Fraco, Estilo
6. Habilidades — Agrupadas por USO_META
7. Condições — Toggle visual de cada condição ativa
8. Inventário — Grid de slots com itens equipados
9. Notas de Sessão — Campo livre
